# Building NXCR v0.4.1 from source

This public repository contains the readable, assembled source used for NXCR v0.4.1 candidate builds. It does **not** require access to the private development repository or an encoded source payload.

## Prerequisites

- The Nintendo Switch homebrew toolchain, including **devkitA64** and **libnx**.
- A POSIX shell, `make`, `zip` and Git.
- The pinned [WerWolv/libtesla](https://github.com/WerWolv/libtesla) source included as a Git submodule at `overlay/libtesla`.

The original verified build environment is `devkitpro/devkita64:20260219`.

## Build

```sh
git clone --recurse-submodules https://github.com/BaskingLeaf/NXCR.git
cd NXCR
make clean
make -j"$(nproc)"
make -C overlay clean
make -C overlay -j"$(nproc)"
make package
```

The sysmodule binary is `exefs.nsp`, the overlay is `overlay/NXCR.ovl`, and the SD-root package generated by the Makefile is `NXCR.zip`. Always install or distribute the **package ZIP**, not an automatic GitHub source ZIP.

If you cloned without submodules, run `git submodule update --init --recursive` before building.

## Package layout

- `atmosphere/contents/00FF0000A53BB667/exefs.nsp`
- `atmosphere/contents/00FF0000A53BB667/flags/boot2.flag`
- `switch/.overlays/NXCR.ovl`
- `switch/NXCR/config.example.ini`

For the public prerelease, the final distribution ZIP must also contain the applicable [GPL licence](LICENSE), [third-party notices](THIRD_PARTY_NOTICES.md), [LICENSES/](LICENSES/) and release notes. Binary and source archives should be attached together, with SHA-256 checksums.

## Reproducibility and attribution

The source was assembled from the v0.4.1 development line for a successful private GitHub Actions candidate build on 14 November 2026. The executable and overlay were independently rebuilt from its source export in that CI environment.

A successful rebuild **does not** establish byte-for-byte binary equivalence across environments or prove licence clearance. See [SOURCE_PROVENANCE.md](SOURCE_PROVENANCE.md), the included licence texts and [TESTING.md](TESTING.md). The final public beta binary is not yet published.
